# سامانه مدیریت لایسنس راهکار دیجیتال

سامانه مرکزی لایسنس، سرویس‌های پولی (شاهکار)، صورت‌حساب و خطاهای نرم‌افزارهای راهکار دیجیتال.

- **پنل مدیریت:** Laravel 13 + Livewire 4 + Tailwind، فارسی و راست‌به‌چپ، تاریخ شمسی
- **API:** امضای HMAC روی درخواست‌ها، پاسخ امضاشده با Ed25519، کش آفلاین در برنامه‌ها
- **اجرا:** روی هاست اشتراکی (DirectAdmin) بدون Redis، Queue Worker یا SSH

## نصب اولیه روی هاست (DirectAdmin)

ساختار روی سرور:

```text
/home/<user>/domains/api.rahkar-digital.ir/
├── core/          برنامه Laravel
└── public_html/   فایل‌های عمومی
```

### ۱. ساخت بسته

در GitHub یک Release با تگ `v1.0.0` منتشر کنید. Workflow «Build Release Package» تست‌ها را اجرا می‌کند و فایل `rdsco-release.zip` را به Release پیوست می‌کند.

### ۲. آپلود

`rdsco-release.zip` را دانلود کنید و از File Manager هاست در ریشه دامنه extract کنید. دو پوشه `core` و `public_html` ساخته یا جایگزین می‌شوند.

### ۳. ساخت دیتابیس و فایل `.env`

یک دیتابیس MySQL بسازید. سپس فایل `core/.env` را از روی `core/.env.example` بسازید و این موارد را تنظیم کنید:

```env
APP_KEY=base64:...
APP_URL=https://api.rahkar-digital.ir

DB_DATABASE=...
DB_USERNAME=...
DB_PASSWORD=...

SETUP_TOKEN=یک-رشته-تصادفی-طولانی
```

برای ساخت `APP_KEY` (روی هر سیستمی):

```bash
echo "base64:$(openssl rand -base64 32)"
```

> `APP_KEY` را بعداً تغییر ندهید. Secret لایسنس‌ها و رمزهای شاهکار با آن رمزنگاری شده‌اند.

### ۴. نصب از مرورگر

این آدرس را باز کنید:

```text
https://api.rahkar-digital.ir/setup?token=<SETUP_TOKEN>
```

جدول‌ها ساخته می‌شوند، کلید امضای Ed25519 تولید می‌شود و حساب مدیر ایجاد می‌شود.

بعد از آن:

1. `SETUP_TOKEN` را از `.env` حذف کنید.
2. از صفحه «حساب کاربری» ورود دومرحله‌ای را فعال کنید.
3. در «تنظیمات ← اتصال شاهکار» اطلاعات سیتاد و شاهکار را وارد کنید و استعلام آزمایشی بگیرید.
4. در «سرویس‌ها و تعرفه» قیمت هر استعلام را تعیین کنید.

### ۵. Cron (اختیاری)

برای پاک‌سازی دوره‌ای در DirectAdmin یک Cron Job هر دقیقه اضافه کنید:

```bash
/usr/local/bin/php /home/<user>/domains/api.rahkar-digital.ir/core/artisan schedule:run >> /dev/null 2>&1
```

بدون Cron هم سامانه کار می‌کند؛ Nonceهای منقضی در حین درخواست‌ها پاک می‌شوند.

## انتشار و بروزرسانی

```text
Push to main  →  Tests (GitHub Actions)
Publish Release vX.Y.Z  →  Build Release Package
پنل ← بروزرسانی ← نصب نسخه  →  Prepare → Install → Finalize
```

1. تغییرات را روی `main` بفرستید. Workflow «Tests» اجرا می‌شود.
2. در GitHub یک Release با تگ جدید (مثلاً `v1.1.0`) منتشر کنید.
3. بعد از پایان Workflow، در پنل به «بروزرسانی» بروید و «نصب نسخه» را بزنید.

**مراحل نصب:**
- **Prepare:** دانلود، بررسی SHA-256، اعتبارسنجی مسیرهای zip و گرفتن پشتیبان از فایل‌ها. سایت فعال می‌ماند.
- **Install:** حالت Maintenance و جایگزینی فایل‌ها.
- **Finalize:** `migrate --force`، بازسازی کش و خروج از Maintenance.

اگر مخزن خصوصی است، یک fine-grained token با دسترسی فقط-خواندنی `Contents` بسازید و در `.env` قرار دهید:

```env
UPDATER_GITHUB_TOKEN=github_pat_...
```

**فایل‌های محافظت‌شده** که هیچ‌وقت بازنویسی نمی‌شوند: `core/.env`، `core/storage`، `public_html/storage`، `public_html/.well-known`، `public_html/.user.ini` و `public_html/php.ini`.

**بازگشت به نسخه قبل:** از همان صفحه، بخش «نسخه‌های پشتیبان». Migrationها برگردانده نمی‌شوند؛ پیش از نسخه‌های دارای تغییر مهم دیتابیس، از دیتابیس پشتیبان بگیرید.

## اتصال نرم‌افزارها

برای برنامه‌های لاراولی از پکیج `sdk/laravel` استفاده کنید؛ راهنمای کامل در [sdk/laravel/README.md](sdk/laravel/README.md) است.

برای زبان‌های دیگر، مستندات کامل API در پنل (منوی «مستندات API») است.

**خلاصه امنیت API:**
- هر درخواست با HMAC-SHA256 و Secret همان لایسنس امضا می‌شود. Secret هرگز ارسال نمی‌شود.
- درخواست‌های قدیمی‌تر از ۵ دقیقه رد می‌شوند. در مسیرهای پولی، Nonce تکراری هم رد می‌شود.
- پاسخ لایسنس با Ed25519 امضا می‌شود و برنامه فقط با کلید عمومی ثابت‌شده آن را می‌پذیرد. یک سرور جعلی نمی‌تواند برنامه را فعال کند.
- برنامه بدون اتصال تا ۷۲ ساعت (قابل تنظیم با `LICENSE_OFFLINE_GRACE_HOURS`) با آخرین پاسخ معتبر کار می‌کند.

## صورت‌حساب

- هر استعلام شاهکار یک ردیف در دفتر مصرف ثبت می‌کند، همراه با تعرفه همان لحظه برای همان مشتری.
- فقط پاسخ‌های قطعی (تطابق یا عدم تطابق) شارژ می‌شوند. خطاهای سیتاد و شاهکار رایگان‌اند.
- «صدور فاکتور» همه مصرف فاکتورنشده مشتری را تا همان لحظه یا تا تاریخ انتخابی فاکتور می‌کند. ردیف‌ها قفل می‌شوند و هرگز دو بار فاکتور نمی‌شوند.
- ابطال فاکتور، مصرف آن را برای فاکتور بعدی آزاد می‌کند.
